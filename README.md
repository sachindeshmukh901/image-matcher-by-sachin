## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The first run needs an internet connection because the face-recognition model files are loaded from jsDelivr and cached by the browser.

## Use

1. Click **Add photos** or **Add folder** and choose reference photos. Original images are saved in this browser's IndexedDB before face processing; they are not uploaded to a server. The app asks the browser to protect this storage from automatic cleanup where supported.
2. Upload a clear, front-facing photo with one visible face.
3. Click **Find matches** to rank stored photos by facial-descriptor similarity.
4. Use the report filters or download the CSV report.

## How matching works

The app uses `@vladmandic/face-api` to detect a face, find facial landmarks, and generate a 128-value face descriptor. It compares descriptors using Euclidean distance and maps that distance to a display score. The percentage is **not a probability**, and no score proves a person's identity. Validate results on your own images and use human review for important decisions.

Old records are reprocessed when the app loads. Images with no detectable face remain in the library but are skipped during matching; use clear images with the face visible and reasonably front-facing. Browser storage survives refreshes but may be removed if the user clears site data or the browser does not grant protected storage. Model files are loaded from `https://cdn.jsdelivr.net/gh/vladmandic/face-api/model`.

## False-positive filtering

The matcher uses Euclidean distance between face descriptors and only displays candidates with distance <= `MATCH_DISTANCE_THRESHOLD` (currently `0.45` in `src/matcher.js`). This is a conservative starting threshold, not a universal identity guarantee. Test it on representative same-person and different-person photos before relying on results. The displayed percentage is a visual score, not an identity probability.


### Matching threshold
The starting face descriptor distance threshold is 0.6 (lower distance means closer). This is not a guarantee of identity; test with varied images and adjust based on false positives/negatives. Face detection uses a larger input size to help with smaller faces. If a saved photo was added using an older version, remove it and add it again so its descriptor is generated by the current model.
